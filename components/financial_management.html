Auto Financial System

A personal financial management system combining ChatGPT-assisted receipt processing, automated expense logging in Google Sheets, and an interactive financial dashboard.

Project Overview

Auto Financial System connects AI-assisted receipt information extraction with automated expense recording and financial visualization. It brings transaction categorization, expense management, and spending analysis into a workflow built around Google Sheets and Google Apps Script.

Main Features

  • AI-assisted receipt processing: use ChatGPT to extract receipt information for expense tracking.
  • Automated expense logging: record expenses in Google Sheets and organize transactions by category.
  • Monthly summaries: review spending totals and compare expenses across months.
  • Interactive dashboard: explore financial charts, spending trends, and category breakdowns.
  • Store analysis: review spending by store to better understand purchasing patterns.

Technical Implementation

Data workflow: ChatGPT assists with receipt information extraction, Google Sheets records expense data, and Google Apps Script supports automated data processing.

Dashboard: JavaScript, HTML, and CSS provide the interface for interactive financial visualization, monthly comparisons, category breakdowns, and store analysis.
